Problem-solving

1. Identify

Find out what the problem really is. What is happening, and what should be happening instead?

2. Check

Test possible causes one at a time, starting with the simplest, until the real cause is found.

3. Document

Write down the cause, the fix and what I learned so the problem is easier to solve next time.

Example: Website button does not work
Identify: clicking the button does nothing.
Check: look for typos in the button's ID, open the browser console for errors, and confirm the script file is linked.
Document: the ID in the JavaScript did not match the HTML. I fixed the name and noted to double-check IDs next time.

Reflection

Before BSIT, I only used computers and had little idea how websites and software were actually made. Studying information technology showed me that every app starts with simple building blocks, and for me those are HTML, CSS and JavaScript. HTML gives a page its structure, CSS gives it style, and JavaScript makes it respond to the user.

The hardest part has been staying patient when my code does not work. I have learned to slow down, read the error, check one thing at a time and write down the fix. Attending webinars on software testing, cyber awareness, office skills and Arduino also showed me how many areas IT covers and how much there is still to learn.

I am still a beginner, and I know I need more practice, more projects and more confidence. I want to become a Junior Web Developer who builds clean, useful websites and keeps learning every day. I am ready to start because I am willing to learn, accept feedback and work hard to improve.
